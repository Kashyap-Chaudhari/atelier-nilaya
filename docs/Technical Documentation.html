Section 1Dual-Framework System Architecture

The Atelier Nilaya platform implements a decoupled, dual-runtime architecture optimized for both editorial prestige and extreme transactional performance:

Architectural Decomposition Django Application (Port 8000): Orchestrates editorial campaigns, category archives, ORM relationships, PBKDF2 superuser authentication, and the administrative dashboard (/admin/).
Flask Application (Port 5000): Lightweight high-speed micro-storefront managing 360° photographic turntable scrubbing APIs, encrypted session shopping bags, and rapid checkout order placement into SQLite.

Section 4Studio Photography Ingestion Tools

Located in tools/, these automated scripts process raw studio camera exposures into production-ready WebP files:

  • tools/import_images.py: Takes a directory of raw photos named <slug>__<metal>__<index>.jpg, auto-crops to square, generates 1200px and 600px WebP files (quality 82, <45 KB), and updates product_images table.
  • tools/check_assets.py: Automated validator confirming that every piece in products has 36 spin frames, 3 stills, and a lifestyle photograph on disk.

Section 6Production Deployment & Server Hardening

Recommended production deployment stack on Ubuntu 24.04 LTS:

  • Application Gateway: Gunicorn WSGI server running 4 worker processes per core behind Nginx reverse proxy.
  • TLS Encryption: Let's Encrypt automated SSL certificate with HTTP/2 and HSTS enabled.
  • Static & Media Serving: Nginx serves /static/ directly with aggressive browser caching headers (Cache-Control: public, max-age=31536000).
  • Database Backup Cron: Nightly automated SQLite snapshot backup using sqlite3 nilaya.db ".backup '/var/backups/nilaya_$(date +%F).db'".
